# ContentType

Type of content (text, image, or multimodality). Note that SafetyContent in requests only accepts text and image.

## Enum

* `TEXT` (value: `'Text'`)

* `IMAGE` (value: `'Image'`)

* `MULTIMODALITY` (value: `'Multimodality'`)
